# LMC 3403 Final Portfolio (Spring 2026)

Barebones multi-page GitHub Pages site scaffold for the final portfolio assignment.

## Included structure

- `index.html` (Landing page with headshot slot + 150+ word bio placeholder)
- `self-assessment.html` (Rhetoric, Process, Modes & Media, Design sections)
- `projects/project-1.html` (Major Project 1)
- `projects/project-2.html` (Major Project 2)
- `projects/project-3.html` (Major Project 3)
- `professional/proj-a.html` (Professional Work 1)
- `professional/proj-b.html` (Professional Work 2)
- `assets/css/styles.css` (Shared site styling)
- `assets/images/`, `assets/docs/`, `assets/media/` (Asset placeholders)
- `.nojekyll` (GitHub Pages compatibility)

## Publish to GitHub Pages

1. Push this repository to GitHub.
2. Go to repository `Settings` -> `Pages`.
3. Under **Build and deployment**, choose:
   - `Source`: **Deploy from a branch**
   - `Branch`: **main** (or your default branch) and `/root`
4. Save. GitHub will publish the site and provide the URL.

## Content checklist

- [ ] Each professional project page has a 100-150 word introduction.
