EchoVision

This project, KLR.ai, was created as an end-to-end technical assignment to demonstrate how AI can turn raw visual data into practical, user-facing guidance. I designed a pipeline that combines YOLO object detection, MiDaS depth estimation, and spatial risk logic to identify important obstacles in a scene, then transforms that data into prompt-ready context for an LLM.

It demonstrates my ability to communicate complex computer-vision systems clearly for non-technical audiences while keeping design choices grounded in real product decisions.

CUDA MatMul Kernels

This CUDA programming assignment focused on GPU acceleration for computationally intensive tasks. I built custom kernels for matrix multiplication, batched operations, FlashAttention, and a 3D heat-equation solver, and compared results against CPU implementations and cuBLAS.

The project pairs implementation with benchmark tables and Nsight Compute analysis to explain where optimizations improved throughput and where bottlenecks remained.
