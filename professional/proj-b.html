Overview (100-150 words)

This project was created as a CUDA programming assignment focused on learning how GPUs accelerate computationally intensive problems. I built custom GPU kernels for matrix multiplication, batched operations, FlashAttention, and a 3D heat-equation solver, then compared their accuracy and performance against CPU code and cuBLAS. Beyond the code, the project includes benchmark tables and Nsight Compute analysis that explain where performance improved and where bottlenecks remained. For outside audiences, it illustrates my ability to translate complex technical work into clear evidence-based findings, connect implementation choices to measurable results, and communicate engineering tradeoffs in a way hiring managers and future employers can understand.
